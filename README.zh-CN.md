## 它是什么

Gongzuotai 是一款尽量不挡路的浏览器。一排标签页——横在顶部或竖在左侧，随你选——其余就是页面。没有工具栏，没有起始页，没有建议侧栏，没有要登录的账号，也没有抢注意力的东西。在同一个输入框里打地址或几个词，就到页面上了。

它使用 **WebKit**，也就是每台 Mac 里已有的引擎（Safari 也在用）。因此整个应用大约只有几兆、打开几乎瞬时：不必再下载、更新并常驻一份 Chromium。

## 它能做什么

- **一个输入框。** 打地址就前往；打词就搜索。会根据你自己的历史补全地址，在按下 Return 之前不会把输入发到任何地方。
- **不挡路的标签页。** 把整天开着的页面固定下来，会缩成字母或图标。上次会话的标签会立刻回来，在你点开之前几乎不占资源。`⌘K` 按名称列出打开的标签。
- **并排两页。** 在「设置 › 标签页」打开分屏，把标签拖到页面上，或选「标签页 › 分屏当前页面」。拖分隔线调整宽度；描边的那一侧接收页面命令。配对与宽度随空间一并恢复，重启也一样。
- **阅读模式。** `⇧⌘R` 把页面收成文章。
- **永久隐藏内容。** `⇧⌘H`，再点 cookie 横幅、订阅遮罩、「相关推荐」栏——它会消失，下次打开同一站点仍在绘制第一帧前就藏好。
- **在页面之前就拦截广告。** 第三方跟踪器与广告网络在网络层被拦住，没有东西可渲染，也谈不上拖慢。默认开启，站点坏了可按站点关闭。
- **跟着你的视频。** `⇧⌘P` 把视频从页面里提出来，放到始终置顶的小窗口，包括盖在其他 App 之上。
- **密码，在钥匙串里。** 登录真正成功后才会询问是否保存；点登录框时在字段下提供已存账号以及该站的通行密钥——与 Safari 类似，不会擅自填写。数据在 macOS 钥匙串中，由系统加密，仅本应用可读。可从 Chrome、Arc、Dia、Brave 或 Edge 一键导入；数据不离本机。
- **浅色、深色，或跟随 Mac。** 边框与页面一并跟随。
- **书签、历史、下载** —— 各是一个面板，可搜索，一键呼出。
- **Chrome 扩展，不必装 Chrome。** 在「设置 › 扩展」粘贴 Chrome 网上应用店链接，或在本应用打开扩展页后点添加。跑在 WebKit 自己的扩展引擎上（Safari 同款）；Chrome 有而 WebKit 没有的 API（书签、历史、下载、侧栏、offscreen、字体、通知、语音、OAuth 登录等）由本应用自行补齐。扩展在拼图按钮后；常用的可固定。自己开发？像 Chrome 开发者模式一样加载未打包文件夹，改完按重新加载。需 macOS 15.4 或更高。
- **安静地自己更新。**（上游发行版）每天检查新版本、下载、校验签名，并在下次启动时换上。不会擅自重启。本 fork 可按 `build.sh` 自行构建与分发。

## 它刻意不做的事

- 不必再装扩展才能「像在家一样」：拦广告、藏杂讯、阅读模式、画中画和密码是内置的；扩展留给其余需求。
- 无同步、无账号、无云。标签、历史和密码只在你的 Mac 上。
- 无遥测、无分析、无向外发送的崩溃报告。离开本机的只有你请求的页面、它们的图标，以及（发行版）每天一次「有没有新版本」的小请求。
- 一个窗口。所谓「新建」只有标签页这一种。

## 隐私，说具体点

| 内容 | 在哪里 | 谁能读 |
|---|---|---|
| 密码 | macOS 登录钥匙串，带本应用标记的普通钥匙串项 | 本应用（发行签名时由对应证书区分）。其他 App 会触发系统权限对话框。 |
| 历史、书签、打开的标签、已隐藏元素 | `~/Library/Application Support/Gongzuotai/` 下的小 JSON | 你。 |
| Cookie 与站点数据 | 应用自己的 WebKit 存储 | 设置它们的站点，与任何浏览器相同。 |
| 扩展 | 解压在 `~/Library/Application Support/Gongzuotai/Extensions/`，数据在 WebKit 扩展存储中 | 各扩展，在你添加时接受的权限范围内。 |
| 其他 | 没有。没有服务器。 | — |

**无痕标签页**（`⇧⌘N`）有独立 cookie 罐，关闭后不留痕迹。

在「系统设置 › 隐私与安全性 › 自动化」中允许的 App，可用 AppleScript 读取标签的地址与标题；无痕标签页永不出现。

## 键盘快捷键

| | |
|---|---|
| `⌘L` 地址 · `⌘K` 切换标签 · `⌘T` 新建 · `⌘W` 关闭 · `⇧⌘T` 重新打开 | `⌘[` `⌘]` 后退、前进 · `⇧⌘[` `⇧⌘]` 上一个、下一个标签 · `⌘1`–`⌘9` 跳转 |
| `⇧⌘S` 标签横排或竖排 · `⌘S` 收起侧边栏 · `⇧⌘B` 收藏本页 | `⇧⌘R` 阅读模式 · `⇧⌘P` 浮窗视频 · `⇧⌘H` 隐藏内容 · `⇧⌘U` 本站已隐藏项 |
| `⌘F` 查找 · `⌘D` 复制标签 · `⇧⌘C` 拷贝地址 · `⇧⌘V` 粘贴并前往 | `⌘Y` 历史 · `⇧⌘J` 下载 · `⌘,` 设置 · `⌥⌘L` 密码 |

`⌘R` 重新加载；`⌥⌘R` 从源重新加载，再次向站点核对缓存，如同 Safari 的「从源重新加载此页」。

`⌃Tab` / `⌃⇧Tab` 沿标签行走；`Tab` 仍属页面，用于表单。`esc` 关掉当前打开的面板。

开启分屏后，`⌥⌘N` 分屏当前页，`⌃⌘←` / `⌃⌘→` 在两页间切换。`⌘W` 关闭聚焦标签，让另一页占满。菜单「标签页 › 分离分屏标签页」可把两边都保留为独立标签。

界面文案跟随 Mac 语言（本轮含简体中文）。可在「系统设置 › 通用 › 语言与地区 › App」中为 Gongzuotai 单独选择语言。

## 给开发者

### 为什么开源

这样任何人都能看清一个处理密码和历史的浏览器在做什么，自己构建，或修掉烦到自己的地方。代码体量可读——约四万行 Swift，除 macOS 自带能力外无第三方依赖，基本一事一文件。

### 构建

- macOS 14 或更高，Xcode 16 / Swift 6 工具链
- `swift build` — 直接从 SwiftPM 二进制跑
- `./build.sh` — 在 `build/`（或 `build/intel/`）打出可双击的 `Gongzuotai.app`，ad-hoc 签名以便本机运行

自己打的包未经公证、也不带上游 Developer ID，首次启动需右键 → 打开（或在「系统设置 → 隐私与安全性」中允许）。这与任何非 App Store / 非公证 DMG 的应用相同。自己构建的钥匙串条目也与已签名发行版分开：钥匙串按签名区分二者。

`./build.sh release dmg` 还会生成磁盘映像 / ZIP。`./build.sh release ship` 额外公证并装订——需要 Developer ID 与 Apple 凭据。

多语言：文案在 `Sources/Search/Resources/Localizable.xcstrings`；在 catalog 补译文，并把 locale 写入 `build.sh` 的 `LOCALES` 即可，无需改调用点。

### 结构概要

- **SwiftUI** 画界面，**AppKit** 补 SwiftUI 够不到的 macOS 边角（标题栏、空白处拖窗口等），**WKWebView** 显示页面。
- 每页一个 `Tab`。网页视图惰性创建——从上次会话恢复的标签在你切过去之前不占进程，所以开着二十个标签启动仍很快。每页在 WebKit 自己的内容进程里，与 Safari 相同；关掉的标签是真的关掉。
- 广告拦截是启动时编译一次的 `WKContentRuleList`，在 WebKit 网络层、发请求之前生效——运行时几乎零开销，不像脚本拦截器。
- 隐藏元素是按站点保存的选择器列表，在文档开始时以样式表注入，因此看不到「闪一下再消失」。
- 颜色都在 `Design.swift` 成对定义浅/深，由窗口外观解析；别处代码不知道当前是哪种模式。
- 扩展跑在 `WKWebExtension`（macOS 15.4+）上。`Crx.swift` 从 Chrome 网上应用店公开更新地址拉取并校验 CRX3。`Extensions.swift` 是浏览器一侧与 WebKit 的约定。`ExtensionShims.swift` 补齐 WebKit 缺少的 Chrome API，并抹平行为差异。`./bench ext-*` 可在测试会话里从 shell 驱动。
- `Sources/Search/` 一事一文件：`Vault.swift` 钥匙串，`Shield.swift` 广告拦截，`Curtain.swift` 隐藏元素，`Session.swift` 启动恢复，`Updater.swift` 更新，`Bench.swift` 测试套接字，等等。

### 不关掉应用也能测

打开 **设置 › 通用 › 允许脚本驱动 Gongzuotai**，运行中的应用会在自己的目录监听 Unix 套接字（仅本用户可读）。仓库根目录的 `./bench` 与之通信：

```
./bench open https://example.com     # 自有标签，在行末，带烧瓶标记
./bench wait 2e7e7e89                 # 等到加载完成
./bench text 2e7e7e89                 # 页面文本
./bench shot 2e7e7e89 out.png         # 截图
./bench click 2e7e7e89 "button.go"    # 点击、输入、提交——走页面自己的事件
./bench probe                         # 窗口状态：打开的面板、模态框、每个窗口
./bench close all
```

Bench 标签不会替你选中，不进会话或历史，由脚本决定何时关掉。这样可以在有人正在使用时测浏览器。

`python3 Tests/split_view.py` 在 `./build.sh` 之后，于隐藏测试会话里通过应用自身模型检查分屏，结束后清掉设置与文件。
